# 个人网站基线

更新：2026-09-06。网站作者：宋林蔚；正式域名：`https://fjnuslw.github.io/`。

## 访问任务

访客能探索作品、源码、演示与文章，理解作者的兴趣与工作方式。公共网站不展示招聘、求职意向、简历或面试资料。

## 信息架构

- 首页 `index.html`：数字花园题签、可翻阅作品册、错落作品陈列、流程模拟、近期手记、作者与联系。
- 项目 `projects.html`：可切换平面/空间的三项代表系统展廊、完整项目档案与三项工具；已有两项项目详情保持原 URL。
- 文章 `blog.html` + `blog/*.html`：六篇文章保留原链接、日期、历史上下文和研究证据。
- 关于 `about.html`：个人介绍、兴趣与工作方法。旧履历页面撤下，保留在本地 `.private/`。
- `demos/local-window-copilot/`：浏览器中的交互模拟，明确不读取真实桌面、不运行本地模型。
- `ai-prep/`：历史求职工作区，保留本地工具和旧 URL 源文件，排除正式发布；不作为履历或岗位实时信息。

## 技术与事实约束

静态 HTML/CSS/JS，无服务端、追踪器、远程字体或模型 API。重要内容和链接直接写在 HTML；JS 只做渐进增强。正式页面必须有唯一 H1、中文语言、viewport、有效 canonical、正确本地链接和清晰键盘焦点。

项目事实依据已有公开页面及作者材料，不凭空刷新。保留数字的样本、时间和语料说明，UI 改版日期不等于项目事实更新日期。`resume-redesign/`、`.private/`、`ai-prep/`、历史归档与临时文件只在本地保留，不提交到公开仓库。

## 发布与维护

使用 `node tools/build-site.mjs` 输出正式静态文件至 `dist/`。发布时只使用该目录；研究与内部文档不可随仓库根目录公开。既有 GitHub Pages 域名和 canonical 保留，额外预览地址不取代正式域名。

每次跨页改动执行 `node tools/validate-site.mjs` 与 `git diff --check`，并依据当前 spec 补充桌面、320px、键盘及失效模式验证。

当前视觉与行为变更见 `specs/2026-09-06-digital-garden/`。视频参考只提供设计语言；页面展示既有项目素材，不包含第三方插画和音频。空间模式基于原生 CSS 透视，窄屏和无 JS 时保留平面作品入口。
