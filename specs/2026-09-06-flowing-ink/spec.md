# 流光墨彩：渐变标题与粒子纸面

日期：2026-09-06 · 状态：已验证

## 问题与证据

用户在数字花园版上线后仍不满意第一观感，指出两点：一是字体单调，标题只有一种颜色，不能吸引眼球；二是背景过于简单，缺少互动与粒子等动态层次。参考视频（用户提供的 4 分 16.57 秒 MP4，与上轮同一素材）中可见：暖橙→玫红的双色渐变大标题、编号与宽字距英文小字、竖排书法装饰、丝绸垂坠般的曲线底纹、粒子与光斑点缀。上一轮为稳妥移除了文字渐变；本轮依据用户明确要求恢复并加强装饰层，同时保留既有内容、路由与可访问性边界。

## 范围与行为

- **FI01 范围与内容边界**：仅增强共享视觉与装饰交互层，不改路由、文案、项目事实与既有功能。四个主页面、六篇文章、两项详情与演示页全部继承同一套令牌；继续沿用 `css/style.css`（令牌）、`css/portfolio.css`（共享视觉）、`js/main.js`（共享交互），不新增全站主题文件或运行时依赖。
- **FI02 标题墨彩**：首屏 H1、各页 H1/H2 采用暖调多停靠渐变（`background-clip:text`），副题 `em` 用玫瑰→梅紫渐变；深色区块标题用亮纸→玫瑰渐变。渐变仅用于 ≥24px 的展示级标题；正文、按钮与小型标签保持纯色。不支持 `background-clip:text` 的环境回退为实色 `color`；打印回退墨色。渐变每个端点与纸底的对比度 ≥3:1（大字 AA），并用脚本记录实际数值。
- **FI03 纸面纹理**：`body` 叠加极低透明度的放射色洗（玫瑰、松绿、暖赭各司其职）与细噪点；首屏用丝绸曲线组与柔焦光斑替代现有三条细线；纹理全部由 CSS 渐变与内联数据 URI 生成，无网络请求，`pointer-events:none` 且不侵入正文。
- **FI04 粒子交互层**：JS 注入一块全屏 `position:fixed` 画布（`z-index:-1`、`aria-hidden`、`pointer-events:none`）。粒子取站内调色板，慢速漂移并小幅呼吸；相邻粒子以发丝线相连；指针 140px 范围内粒子被轻推并与指针连线。粒子数量按视口面积限流（桌面 ≤90、移动 ≤40），设备像素比按 ≤2 渲染；画布不滚动、不遮挡内容、不拦截事件。
- **FI05 动态节制**：粒子与光斑动画尊重 `prefers-reduced-motion`、既有「暂停花园动态」按钮与页签隐藏状态；暂停时停止 `requestAnimationFrame` 并保留最后一帧静态画面。光斑浮动只作为装饰，禁止入场强制滚动或内容遮挡。
- **FI06 降级与边界**：无 JS 时只有静态纹理，无画布，内容与导航完整可读；触屏滚动与横划不受影响；打印时隐藏纹理、粒子与装饰光斑；320px 下纹理与粒子不造成横向溢出。
- **FI07 验证**：`node tools/validate-site.mjs`（源与 dist）、`node tools/build-site.mjs`、`node tools/stamp-assets.mjs`、`git diff --check`；浏览器桌面 1440/390px 与 320px 视口截图核对渐变、纹理与粒子；核对控制台无错误；模拟无 JS 与减少动态；对比度脚本输出渐变端点数值。
- **FI08 发布**：以 fjnuslw 身份提交并推送 `https://github.com/fjnuslw/fjnuslw.github.io` main；发布仅使用 dist 白名单；单独核对 GitHub Actions 与线上页面，不以推送成功替代部署证据。

## 设计与取舍

详见 [design.md](design.md)。视频只提供设计语言：渐变标题、编号系统、曲线底纹与粒子氛围转译为本站令牌内的原生 CSS 与 Canvas；不复制其中人物插画、音频、作者身份与任何第三方素材。自定义光标替换（视频中的橙色圆点）因伤害指针精确性且触屏无等价物，本轮不做，以指针粒子场替代互动感。
