# 纸墨重排：去模板化的视觉系统与动态细节

日期：2026-09-06 · 状态：实施中。取代 `2026-09-blue-white` 的视觉验收结论（P01 内容边界与发布流程继续有效，并入本 spec 重述）。

## 问题与证据

用户对蓝白版的三点判定，附可核对依据：

1. 「AI 味重」。对照公开总结的 AI 模板化特征（见 research.md）：系统默认无个性字体（Segoe UI）、近 Tailwind 默认蓝 `#1748ed`、居中 eyebrow + 大标题模板句、等距圆角阴影卡片、backdrop-blur 玻璃导航、通用 fade-in——当前站点逐项命中。模板特征叠加是观感雷同的原因，不是单点颜色问题。
2. 「排版丑、风格不统一」。首页、项目页、文章页各自为政：卡片、行列、留白比例混用；蓝白两色大面积平涂缺少印刷层级（线、字重、灰阶）。
3. 「不要放我的照片」。`about.html` 引用 `assets/song-linwei.jpg`，照片在公开仓库与发布白名单（`tools/site-manifest.mjs`）中。

用户要求的「亮眼动态表现」按 research.md 的结论收敛为少量相互呼应、可降级的动效，不做堆砌。

## 行为契约

### 隐私与内容

- **P01 照片撤除**：公开仓库不再包含 `assets/song-linwei.jpg`；`about.html` 改用自绘「印章式身份牌」SVG（含 `title`/`desc`）。照片文件移入本地 `.private/`（gitignore 内），不删作者资料。发布白名单、sitemap、结构化数据同步去引用。
- **P02 内容边界**（继承 blue-white P01）：公开页面、导航、检索、站点地图不出现求职入口、简历、招聘/面试资料；`ai-prep/`、`resume-redesign/`、`tmp/`、`specs/`、`docs/`、`.private/` 不进入发布产物；保留六篇文章原 URL 与日期、两项项目详情 URL、演示路由与事实描述。

### 视觉系统「纸墨」

- **V01 色彩与质感**：暖纸底 `--paper`、墨色正文 `--ink`、朱砂强调 `--vermilion`、松绿辅助 `--pine`；深墨色用于隔段与页脚制造节奏。禁用蓝紫渐变、玻璃拟态、彩色投影。强调色文字对比度满足 WCAG AA（小字 ≥4.5:1），实际数值记录在 verification.md。
- **V02 字体三声部**：衬线显示字体（Georgia/宋体系统栈，无网络字体）承载大标题与署名；无衬线正文；等宽字体承载编号、标签、状态与读数。三种声音有固定分工，不混用。
- **V03 线框版式**：以 1px 细线、编号与留白组织层级，替代阴影卡片；圆角 ≤2px。作品与笔记采用「编号索引行」列表而非等距卡片网格；首页 hero 非对称双栏（文案 + 交互展台）；跨页共享同一导航、页脚、章节头结构。
- **V04 图像策略**：项目图、吉祥物、文章 SVG 全部保留复用；新增装饰图形为自绘 SVG 或纯 CSS；不引入外链图片、图标库或远程字体。
- **V05 文案去模板**：移除「HELLO, I'M …」式开场与空洞标语，改用具体事实与作者口吻；英文 eyebrow 标签仅在确有检索/索引语义时保留，并统一为等宽小字。

### 动态细节（全部可降级）

- **M01 信号地形粒子场**：首页 hero 内一块 canvas：墨色点阵 + 少量漂浮码点（`{ } ; ⇄` 等），指针产生扰动与连线，点击产生一次涟漪；单画布、≤1.5 DPR、节流绘制；离屏、后台标签、`prefers-reduced-motion` 或全局暂停时停帧；纯装饰，不承载任何内容。
- **M02 文字解码**：hero 标题进入时一次性字符解码（约 0.9s）；导航链接 hover 时轻量 scramble；减少动态偏好下直接呈现最终文字。解码不改变 DOM 语义（`aria-label` 固定原文）。
- **M03 反馈动效**：主要按钮磁性微位移（仅精确指针）；索引行 hover 位移 + 朱砂序号；章节标题朱砂下划线绘制；统计数字一次性计数；关键词跑马灯（hover/聚焦暂停，减少动态时静态展示一行）。
- **M04 现场感**：页脚显示作者时区（UTC+8）实时时钟，纯本地计算；加载失败或无 JS 时显示静态文本「福州 · UTC+8」。
- **M05 既有交互保留换肤**：Ctrl/Cmd+K 站内导览（含失败回退）、阅读进度条、文章筛选、项目展台预设流程演示（运行/暂停/重播、模拟边界标注）全部保留，视觉随新系统重绘；支持的浏览器启用跨页 View Transitions。

### 质量门槛

- **A01 可用性底线**：无 JS 时全部正式内容可读、主导航可用；键盘可完整操作（焦点可见、模态焦点圈定）；`prefers-reduced-motion` 下所有动画降级且内容完整；320/390/768/1440px 无横向溢出，正文 ≥16px；打印样式保留正文；动态效果不隐藏内容、不劫持滚动。
- **G01 校验**：`node tools/validate-site.mjs`、`node tools/build-site.mjs`、`git diff --check` 全部通过；浏览器实测桌面与 320px 视口。
- **G02 发布**：以 fjnuslw 身份推送到 `origin`（https://github.com/fjnuslw/fjnuslw.github.io）main 分支，不 force push；GitHub Pages 通过白名单工作流发布 `dist/`，部署成功证据（SHA/Actions 状态）记录在 verification.md。

## 范围与取舍

- 保留：站点信息架构、全部内容事实、既有工具链（validate/build/manifest/stamp）、无框架约束。
- 替换：`css/style.css` 与 `css/portfolio.css` 全量重写（不叠加覆盖层）；`js/main.js` 重写但保留已验证的导航/导览/筛选逻辑骨架；公开页面 HTML 重写外壳与版式。
- 不做：暗色模式切换、多语言、WebGL、远程字体、图标库、新依赖。
- 项目展台沿用蓝白版 D01/D02 的交互契约（预设三步流程、暂停/重播、模拟边界），仅重新视觉实现。
