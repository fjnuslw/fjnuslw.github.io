01

活跃开发2026.08—至今企业落地 · 全栈 / Agent

星途知汇

把员工口中的经验变成经过确认、审核和权限控制的企业知识。

Problem

隐性经验散落在口头交流与个人记忆里；传统填表阻力高，知识发布还必须经过本人确认、业务审核与权限校验。

My contribution

设计对话采访与经验卡片；用 LangGraph.js + PostgreSQL Checkpointer 编排可恢复状态；实现权限优先 Hybrid RAG、飞书 OAuth 2.0 + PKCE 与通讯录事件同步。

Result

10 部门 / 30 人真实完成在职员工目录同步验收；打通“员工原话 → 确认 → 业务审核 → 版本发布 → 权限内复用”链路。

  • LangGraph.js
  • PostgreSQL
  • Hybrid RAG
  • Qwen
  • Feishu

02

已开源2026.07—2026.08独立开发 · Agent Harness

Local Window Copilot

为本地小模型补齐屏幕感知、上下文装配、长期记忆与原生交互。

Problem

1.3B 级本地模型不应被要求同时完成可靠读屏、历史筛选和记忆维护；不使用云端 API 时，更需要 Harness 先整理模型真正需要的上下文。

My contribution

让 OCR 负责文字、数字与位置，VLM 负责布局和用户行为理解；以 SQLite 持久化窗口观察、完整对话与长期记忆，并把 CLI 命令集成进原生悬浮聊天窗。

Result

GPU OCR 单图 0.347–0.487 s，较 CPU 加速 2.64–3.26×；对话和确认后的稳定信息可在重启后恢复。

  • Python
  • MiniCPM-V
  • RapidOCR
  • SQLite
  • Win32

03

开源验证原型2026.07—2026.08独立重构 · Agent / RAG

OpenSOP Agent

把跨站点人工编排的 SOP，改造成有证据、有约束、可审核恢复的生成流程。

RetrieveDraftApproveExport

Problem

新 Model 的多站点 OI 依赖人工录入、图片编排和逐级审核；历史路线、参数来源与媒体证据一旦脱节，生成结果就无法交付。

My contribution

建立 Model 包 / 站点 OI / 作业 Step 领域模型；以混合 RAG 和受约束 Draft 生成内容，Qwen2.5-VL-7B 处理图片候选绑定，LangGraph 支持审核中断与恢复。

Result

验证 40 OI / 324 Step / 80 媒体证据 / 24 Lesson / 12 隔离任务，支持 Lesson 审批沉淀与 Excel / ZIP 导出。

  • FastAPI
  • LangGraph
  • Qwen2.5-VL-7B
  • Hybrid RAG
  • OpenPyXL
