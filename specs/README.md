## 文档规则

1. 文件夹用 `YYYY-MM-short-name`；状态为草案、实施中、已验证、已取代。
2. 每项需求使用稳定 ID，描述触发条件、结果与失败边界。
3. 实现与需求冲突时先修改其中错误的一方，并记录原因；禁止勾选不成立的验收项。
4. 旧规范移至 `docs/archive/`，保留来源日期和替代关系；研究证据保留在 `paper_search/`。
5. 不为每次微小样式修改增加一套文档。新变更使用 [模板](templates/change.md)。
