展开项目过程 +

遇到的问题

悬浮窗抢焦点、页面滚动和异步返回会造成错窗、画面漂移、证据离开视口及结果串线；只保存截图也无法支撑连续追问。

实现过程

在抢焦点前锁定 PID / HWND，以 PinnedScene 和 ownership / epoch fencing 固定物理窗口；构建“全帧 OCR → ScreenMap → VLM”观测链路、跨帧 Evidence Graph 及 SQLite WAL 双账本。

项目记录

支持滚动后继续追问离开视口的真实可见内容；完整 Thread / Generation、版本化 Capsule 与用户确认的有界 Notebook 均可持久化和恢复。

展开项目过程 +

遇到的问题

新 Model 的多站点 OI 依赖人工录入、图片编排和逐级审核；历史路线、参数来源与媒体证据一旦脱节，生成结果就无法交付。

实现过程

建立 Model 级 SOP 包 / 站点级 OI Draft / 有序作业 Step 领域模型；以 Dense + 字符级 Lexical、RRF、可插拔 Reranker 和元数据排序选取完整主路线，通过 Pydantic Schema、来源白名单与人工图片确认约束 Draft。

项目记录

验证 40 OI / 324 Step / 80 媒体证据 / 24 Lesson / 12 隔离任务，支持 Lesson 审批沉淀与 Excel / ZIP 导出。
