Intrinsic Attention as Navigator: A Non-Generative Retrieval Method for Multi-Hop Queries

EMNLP 顶会一作 ↗

1提出免训练、非生成式多跳检索框架 IN-Retriever，直接读取 Qwen3-Embedding-4B 内部注意力作为下一跳导航信号，迭代构建多跳证据链，无需模型微调或生成中间推理文本。

2提出 Bridge Focus Score（BFS）定位任务相关注意力头，通过句子筛选、Token 峰值聚合及边界扩展提取桥接线索；进一步采用正交投影剔除 Query Embedding 中已覆盖语义，并融合原始相关性、残差意图和词面匹配完成候选文档重排。

3基于 ChromaDB / HNSW、优先队列和 Beam Search 实现多路径证据搜索；仅使用 4B 骨干，超过两种 7B / 8B 强嵌入基线。

ESRA: Training-Free Multi-Hop Agentic RAG with Explicit Evidence-State Transitions

AI Open · 与导师共同一作

提出 ESRA，将多跳查询拆解为“检索起点 - 关系需求 - 步骤结果”的可执行步骤，并用 branch 结构组织多对象查询中的独立执行路径；PlanState 维护当前分支、活动步骤、中间结果与答案目标。设计 Search / Probe → LLM Commit → State Write-back 执行流程：Search 按当前关系检索文档，Probe 从证据句中抽取候选结果；候选接受后，由 State Write-back 将结果写入 PlanState，并将来源文档与证据句按步骤写入 EvidenceSpace，推进后续执行。
