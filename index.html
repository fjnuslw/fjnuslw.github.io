SYS–01 2026.08—至今 企业落地 · 全栈 / Agent 活跃开发

Enterprise Agent

星途知汇

让一次员工对话，经确认、审核与权限检索，成为可复用的组织知识。

问题
经验散落在对话中，来源、可见范围与发布责任难以追踪。
本人贡献
以 LangGraph.js + PostgreSQL Checkpointer 编排采访与发布状态；构建权限优先 Hybrid RAG，并接入飞书 OAuth 2.0 + PKCE 与通讯录事件同步。
结果
完成 10 个部门 / 30 名在职员工目录同步验收；支持来源白名单、证据不足拒答与检查点恢复。
  • LangGraph.js
  • PostgreSQL
  • Hybrid RAG
  • pgvector / pg_trgm
  • Feishu

SYS–02 2026.07—2026.08 独立开发 · 开源 已交付

Local Agent

Local Window Copilot

为 1.3B 级本地多模态模型补齐观察、记忆、交互与恢复能力。

问题
小模型既要理解窗口内容，又要维持长对话与原生桌面交互，且不能依赖云端 API。
本人贡献
构建 MiniCPM-V 4.6 Thinking 的完整 Agent Harness：OCR 负责文字、数字与位置，VLM 负责布局和行为；SQLite 持久化窗口观察、对话与长期记忆，并将 CLI 命令接入原生悬浮窗。
结果
GPU OCR 单图 0.347–0.487 s，较 CPU 加速 2.64–3.26×；支持流式回答、思考状态、取消与重启恢复。
  • Python
  • FastAPI
  • MiniCPM-V
  • RapidOCR
  • SQLite
