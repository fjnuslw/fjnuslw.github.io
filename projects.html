01 · WENQU / REPOSOCRATIC（独立开发 · 2026.08 – 至今）

86.5% · 83/96

个性化面试 Agent 与 9B 模型后训练系统：融合题库、面经与项目材料由 LLM 组卷，基于 Pi、Harness 校验与只读仓库工具完成多轮源码取证，将“先读懂实现再提问”做成可蒸馏、可在线 RL 闭环优化的任务。

  • 轨迹蒸馏（ms-swift / LoRA SFT）：构建 20 项目、100 场景、820 监督目标，vLLM 补算 Top-32 概率，以 CE + 分组 KL 完成 Qwen3.8-27B → Qwen3.5-9B 蒸馏；结合 SP2/FSDP2、激活检查点与分块损失，双卡训练最长 11.7 万 token。
  • 在线 Agentic GRPO：校准事实、提问与完成奖励，基于 HF Transformers 采集多轮轨迹，自定义 GRPO 与 action mask 保留上下文、仅优化模型动作；固定蒸馏参考策略，完成 73 组采样、67 次更新与检查点恢复闭环。
  • 同条件评测与开源：在 24 个训练外项目家族对照基座、蒸馏及 RL（三种模型各 96 条、共 288 条轨迹），最终完成率 86.5%（较基座 +10.4 个百分点）。
