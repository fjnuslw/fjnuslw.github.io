01 / IN-RETRIEVEREMNLP 2026 · 已录用第一作者

Intrinsic Attention as Navigator: A Non-Generative Retrieval Method for Multi-Hop Queries

回答跨文档问题时，当前证据往往只解决了一部分：还需要找到连接到下一份材料的线索。IN-Retriever 从 Qwen3-Embedding-4B 的内部注意力中寻找这样的桥接线索。

通过 Bridge Focus Score 选择注意力头，把已收集证据、剩余查询意图与路径得分组织为检索状态；结合束搜索探索多条路径，用正交投影残差调整排序，在不生成中间推理文本的情况下继续取证。

方法记录：免训练多跳检索 · 注意力桥接 · ChromaDB / HNSW · MuSiQue / 2Wiki 对照与消融

02 / ESRANAACL · 在审与导师共同第一作者

ESRA: Training-Free Multi-Hop Agentic RAG with Explicit Evidence-State Transitions

复杂问题通常有多个分支，后一步又依赖前一步的结果。ESRA 用显式任务状态保存执行位置、已确认结果与完成情况，让 Agent 按依赖推进。

Search 与 Probe 工具形成证据候选；模型判断候选是否满足关系需求，接受后写回状态，拒绝后切换候选，耗尽时改写查询。临时候选与已确认结果分开保存，后续检索、比较和回答继续使用相应来源文档与证据句。

方法记录：依赖规划 · taskState · 候选验证 · 执行记忆与上下文管理

HOW I WORK

一些习惯。

01 / TRACE

把来源留下。

读到一个结论，追到文档或代码；生成一份内容，让它能回到原始材料。

02 / TEST

先做一个小实验。

用一个可以复现的例子判断方向，再把它放回完整系统。

03 / WRITE

把过程写清楚。

记录输入、条件和失败。以后重新打开项目，还知道当时为什么这样选。
