Windows · Observation / Evidence Harness

Local Window Copilot

面向本地小模型的 Windows 视觉上下文引擎：严格捕获当前 HWND，把 OCR 与视觉理解保存为不可变事实，再把同一物理窗口中真正见过的内容投影成可追溯证据，供每轮对话读取。

Problem

桌面 Agent 的难点不是“看屏幕”，而是证明自己看到了什么。

窗口快速切换会引入错窗、迟到结果与时间错配；相同画面也可能在不同时间代表不同事件。项目因此把捕获、识别、出现时间和对话快照拆成可验证的事实链。

01

窗口身份必须严格

截图绑定 PID/HWND；失败就显式返回，不使用整屏、同名窗口、旧截图或全局 latest 兜底。

02

内容与时间分离

Observation 表示唯一识别画面，Occurrence 表示一次真实看见；相同内容可以复用识别，但不能丢掉新的时间证据。

03

迟到结果不能写回

事实、布局与 PENDING 状态同事务提交，epoch / revision fencing 只允许当前上下文更新，过期任务自动失效。

Pipeline

从物理窗口到固定证据快照

Watcher、手动观察和对话刷新共用同一个 HarnessRuntime。对话打开时冻结外部窗口，每一问重新观察同一 HWND，并在生成前固定 occurrence，单轮中不漂移。

Data model

事实不可变，证据可重建，语义视图可选。

系统不把 Activity 或业务标签当作回答正确性的前置条件。当前页直接读取固定 Observation；离屏历史再通过 Track 与共同见证帧还原 Evidence Fragment。

Design

关键工程决策

每一层只承担可验证的职责，避免让 VLM 猜坐标、让摘要替代事实，或让语义增强层阻塞当前页回答。

OCR

几何事实不交给 VLM

RapidOCR 读取完整 HWND；ScreenMap 用分隔线、留白与阅读顺序组织主要内容区，VLM 只补充裁剪区域的视觉语义。

GRAPH

跨帧证据关联

Evidence Graph 结合文字、归一化几何、多运动层与最近 track bank；不使用应用白名单、业务关键词或消息正则。

GAP

局部失败不拖垮时间线

单条投影失败只留下 FAILED gap，后续 occurrence 仍可使用更早 READY 证据继续。

PIN

单轮证据冻结

模型只看 Current Scene、历史 Evidence Timeline、真实 Dialogue Tail 与 Question；当前页 OCR 不重复装载。

QUEUE

统一模型调度

INTERACTIVE、FOREGROUND、BACKGROUND 共用一个优先级模型调度器，OCR 独立运行，不占模型槽。

LOCAL

数据留在本机

截图、OCR、SQLite 事实账本与 llama.cpp 推理均在本地完成，默认不引入云端连接器或自动桌面操作。

Boundaries

当前边界与验证结果

项目主动缩小承诺范围：先把事实账本与证据链做对，再讨论向量库、LangGraph、连接器或自动操作。

01

只承诺单 FastAPI worker；多 worker 需要数据库 lease 与跨进程模型队列。

02

Ambient Memory 只保存屏幕真实展示过的内容，从未出现的聊天历史需要显式 Deep Read。

03

暂不引入向量库、LangGraph、应用连接器或自动桌面操作；它们不能替代正确的事实账本。

04

Activity 是体验增强，不是 Agent 正确回答当前页面的前置条件。
