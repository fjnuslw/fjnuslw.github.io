# 数字花园：画册与空间展廊

日期：2026-09-06 · 状态：已验证

## 问题与证据

用户仍不满意纸墨版，希望参考所提供的 4 分 16.57 秒网站视频，进行整个个人网站的大更新，按 spec 管理并以 fjnuslw 推送至指定仓库 main。参考中的画册叠层、浮动导航、空间展廊和错落排版，比现有等宽索引行与工作台面板更接近用户期待。取代旧版视觉要求，不改写历史验收记录。

## 范围与行为

- **DG01 内容与路由**：覆盖四个主页面、六篇文章、两项项目详情与独立演示共 13 页。保留既有链接、文章日期、全文、项目证据和功能。禁止新增求职、简历、照片入口；不公开本地制作材料。
- **DG02 全站视觉**：奶油纸底、玫瑰/梅色强调、青绿色展墙；衬线中文大标题、细线、书页边与克制阴影。浮动圆角导航、章节题签与统一页脚跨页一致。正文不小于 16px，常用标签不小于 14px，小字对比度至少 4.5:1。
- **DG03 首页画册**：首屏呈现作者、领域、明确的作品/笔记链接和带透视的项目书页。可手动翻阅三项真实项目，当前作品的名称、素材、说明、链接同步，上一页/下一页循环切换并播报当前页。不自动翻页，无 JS 呈现第一项并保留全部作品链接。
- **DG04 作品展廊**：项目页提供现有三项系统的平面/空间展示与前后选择；空间模式以透视与景深强调选中作品，平面模式可直接读完。按钮、方向键（仅在展廊内）、触屏横划均可选取；点击作品进入已有项目位置。无 JS/窄屏默认平面，不劫持页面滚动，不增加 WebGL 或第三方库。
- **DG05 阅读版式**：笔记列表使用刊物式题头、精选文章和可筛选档案；六篇原文章内容完整，正文窄栏，图表代码局部滚动。关于页采用作者题签和工作方法编排；所有详情页使用相同设计令牌与导航页脚。
- **DG06 既有交互**：保留站内导览、Ctrl/Cmd+K、文章目录/进度、主题筛选、三步流程模拟的运行/暂停/重播与独立演示。检索加载失败显示明确状态，并保留静态导航。模拟说明保持可见。
- **DG07 动态降级**：书页轻浮动、精确指针小角度透视、按钮反馈与翻页过渡组成同一节奏；全局暂停、减少动态、后台页签时停止连续动画。无字符乱码解码、强制滚动或遮挡内容的入场。无 JS 时正式内容和导航均可读。
- **DG08 验证**：桌面 1440px、320px 全路由无页面溢出；补充 390/768px 主页面，键盘、触屏、无 JS、减少动态、检索失败、200% 字体与打印。运行 validate/build/dist validate/diff 检查，证据引用真实文件与结果。
- **DG09 发布**：以已配置的 fjnuslw 身份提交并非强制推送至 `https://github.com/fjnuslw/fjnuslw.github.io` 的 main；仅白名单 dist 进入 GitHub Pages。单独核对 GitHub Actions 与线上页面，不用推送成功替代部署证据。
- **DG10 字体与配色专项**：用户在预览中强调字体、颜色同等关键。标题改用本地托管的 Noto Serif SC 子集（保留 OFL 许可），统一 500–700 的书刊字重与字距；正文继续使用系统无衬线。纸白背景、墨紫正文、灰玫瑰交互、深青绿展墙各有明确用途。字体文件目标小于 500 KiB，`font-display:swap`，失败时回退系统宋体；浏览器确认字体实际加载与标题完整。新内容维护须能重建字形子集，构建不依赖网络字体服务。

## 设计与取舍

详见 [design.md](design.md)。用已有项目素材和可访问的原生界面空间变换转译参考视频；不复制视频中的人物插画、音乐和作者身份，不把空间展廊宣称为三维园林引擎。新增运行时依赖为零。共享视觉只维护 `css/portfolio.css`，基础排版和令牌维护 `css/style.css`，共享行为维护 `js/main.js`。
