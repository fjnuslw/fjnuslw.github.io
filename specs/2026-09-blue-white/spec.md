2026-09-06 · 实施中。用户否定上一版视觉结果，要求撤下招聘内容、统一全站、蓝白交替与动态渲染，并推送指定仓库 main。

## 行为契约

- **P01**：公开页面、导航、检索、站点地图、标题和结构化数据不出现求职入口、实习意向、可入职时间或简历。ai-prep、resume-redesign、tmp、含求职背景的旧归档保留本地，并从本次公开仓库文件树排除；不重写 Git 历史。
- **V01**：采用蓝色章节开场、白色内容区、深蓝正文的一套系统；字体、最大宽度、留白、按钮、线条、圆角一致。替换旧 CSS 实现，不能再在旧主题末尾叠加整站覆盖。
- **V02**：重新组织首页、项目与关于。首页聚焦作品、交互和笔记；项目内容按统一项目行展开，详情页与文章头尾采用同一导航与蓝白结构。保留项目事实、六篇文章和历史日期。
- **D01**：首页真实渲染项目展台：三个项目切换同步名称、说明、图像/流程与目标链接；切换有短过渡，语义与内容一起更新。所有演示标注预设流程，不冒充连接模型。
- **D02**：展台支持运行一次三步流程；节点、连线、状态记录逐步更新；可暂停/继续、重播。背景点线随时间和指针变化；离屏、后台、减少动态偏好时停止。所有主要内容不依赖动画。
- **D03**：项目行悬停/聚焦反馈、详情展开、文章筛选过渡、当前章节与阅读进度形成一致反馈；触摸和键盘有等效操作，不劫持滚动。
- **A01**：320/390/768/1440px 无页面溢出；正文不小于 16px，对比度 AA；无 JS 可阅读与导航，减少动态可用；模态保持焦点与失败出口。
- **G01**：完成源站/产物校验、diff 检查、桌面与手机浏览器验收，再提交到 https://github.com/fjnuslw/fjnuslw.github.io 的 main。禁止 force push，保留用户其他本地工作。
- **G02**：GitHub Pages 使用白名单产物；验证实际 main SHA 和部署状态，公开链接不以私有 Sites 预览替代。
