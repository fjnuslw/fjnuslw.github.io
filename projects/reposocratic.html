WenQu / RepoSocratic

先读懂项目实现，再提出有依据的问题。WenQu 负责基于题库、面经与项目材料的多轮组卷和追问；RepoSocratic 将只读源码取证与提问策略做成可蒸馏、可在线 GRPO 迭代的 9B 后训练闭环。

01 / 系统分工与只读取证

WENQU · 面试 AGENT

融合题库、面经与项目材料由 LLM 组卷，基于 Pi 运行多轮 Agent；由 Harness 校验层约束题目来源、阶段推进、顺序与只读仓库工具取证。

REPOSOCRATIC · 后训练系统

统一教师与学生的只读取证工具和代码快照，公开完整数据管线、ms-swift 蒸馏扩展训练器、HF Transformers 在线 GRPO 循环与固定协议评测脚本。

RELEASE · 两版 LORA 权重

在 Hugging Face 公开 K2 概率蒸馏版与 RL-73 在线 GRPO 版 LoRA 权重（适配 Qwen3.5-9B 基座）；运行时需叠加对应基座模型与推理环境。

接入边界：源码与模型卡已建立清晰接口，但 WenQu 在线会话尚未调用该 9B 服务；本站为纯静态记录，不在浏览器内运行训练或模型。查看接线设计 ↗

02 / 轨迹蒸馏与在线 GRPO

01 / DATA20 项目 · 100 场景
02 / TARGET820 个监督目标
03 / TEACHER27B 轨迹与 Top-32 概率
04 / DISTILL9B LoRA CE + 分组 KL
05 / ONLINE RL73 组采样 · 67 次更新
06 / EVAL24 家族 288 轨迹对照

轨迹蒸馏（MS-SWIFT / LORA SFT）

使用 vLLM 补算教师（Qwen3.8-27B）Top-32 token 概率分布，在 ms-swift 上以交叉熵（CE）+ 分组 KL 损失完成向 Qwen3.5-9B 的轨迹蒸馏。结合 SP2 / FSDP2、激活检查点与分块损失，在双卡环境下支持最长 11.7 万 token 的长程轨迹训练。

在线 AGENTIC GRPO

校准事实依据、提问质量与任务完成奖励，基于 HF Transformers 采集多轮工具交互轨迹；自定义 GRPO 配合 action mask 保留完整工具观察上下文、仅优化模型生成动作。固定 K2 蒸馏策略为参考模型，完成 73 组采样、67 次有效更新与检查点恢复闭环。

训练规模来源：RepoSocratic 公开实验记录 ↗。上述长度与计数仅反映本项目实验条件，不作为通用硬件吞吐基准。

03 / 同条件固定协议评测

2026-09-25 固定协议汇总：24 个训练外项目家族 × 2 个场景 × 2 个随机种子，基座、蒸馏与 RL 三种模型各 96 条、共 288 条轨迹。RL-73 检查点在开发集上预先锁定后再运行最终对照。
