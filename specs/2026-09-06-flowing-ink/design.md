## 视觉令牌（叠加在数字花园令牌之上）

- 渐变标题：`#a8603a`（暖赭）→ `#a04e67`（玫瑰）→ `#63497d`（梅紫），仅限展示级标题。
- 副题强调：`#a04e67` → `#6d4a80`。
- 墨色渐变（纸面 H2）：`#2d2634` → `#514653`。
- 亮渐变（深色区 H2）：`#f8f5ef` → `#e8bbc3`。
- 纸面色洗：玫瑰 `#d9c3d8`、松绿 `#cfe0d5`、暖赭 `#ecd9bf`，透明度 ≤ 0.35，叠加在 `--paper` 之上。
- 粒子调色板：`#a04e67`、`#315951`、`#a8603a`、`#6d4a80`，单粒 alpha ≤ 0.5，连线 alpha ≤ 0.14。

## 粒子场行为

- 画布由 JS 注入（`initGardenCanvas`），fixed 全屏、`z-index:-1`、`aria-hidden`、`pointer-events:none`；无 JS 时不存在。
- 密度：`min(90, round(area/16000))`（桌面），移动端除以 24000 且上限 40；DPR 取 `min(devicePixelRatio, 2)`；resize 防抖重建。
- 运动：每粒子恒速漂移 + 正弦呼吸（半径与 alpha 微变）；与最近邻 ≤110px 时绘发丝线；指针周围 140px 内按距离反比轻推，并与指针连线（星座感）。
- 停止条件复用 `canAnimate()`：`prefers-reduced-motion`、`.motion-paused`、`document.hidden` 任一为真即停帧保留静态画面；恢复时继续，不重置粒子。

## 边界

- 渐变不进入正文、按钮、表格、代码与小型标签；WCAG AA 由端点对比与字号保证，并在验收中记录数值。
- 纹理与粒子均不承载信息，`aria-hidden`，打印与高对比模式下自动退化为纸底墨字。
- 不复制视频中的插画、音乐、作者署名与交互文案；自定义光标替换不做（指针精确性、触屏无等价物）。
