# 2026-09 个人网站重构

日期：2026-09-06 · 状态：已验证（本地） · 替代：旧 `search/SPEC.md` 及零散前端排版方案。发布状态单列在验收记录中。

## 1. 从访问场景定义目标

访客当前面对大量工程术语、重复的“证据链”文案、同构面板和深色纸张主题。项目内容已有积累，但视觉主次和探索方式不足以呈现个人特点。旧规范与试验资料散落在 search、tmp、ai-prep，容易被误认为当前要求或正式能力。

本轮交付一个有作者气质的作品站：先看到人和作品，再逐层进入实现。将“增加很多亮眼表现”具体化为少量可操作、相互呼应的小设计，避免动画数量挤占内容。不能保证所有访客的主观印象；用可观察的设计、完整交互与质量门槛验收。

## 2. 视觉与内容

- **V01**：采用清亮白底、深墨文字和钴蓝主色。首页用大字号姓名、非对称作品展台、宽窄交替的作品行形成新轮廓；不只给旧卡片换颜色。
- **V02**：首页缩短重复架构说明，保留三项项目、两段经历、文章与联系；项目页承担技术细节。项目、文章、履历、关于及全部文章/项目详情共享导航、字体、色彩和页脚。
- **V03**：正文至少 16px，标签通常至少 14px；文章宽度约 740px，宽表格/代码局部滚动。320、390、768、1440px 下不得撑宽页面，200% 文字放大仍可操作。
- **V04**：保留真实作者照片、现有项目资产与文章原图；流程图写 title/desc。所有内容图有准确 alt，不复制参考站的代码或素材。

## 3. 有用的小交互

- **I01 悬浮导航助手**：所有正式内容页面出现“去哪里”入口，点击或 Ctrl/Cmd+K 打开原生 dialog。给出项目、文章、履历、关于及当前页章节；按标题、标签、摘要检索文章。中文可用，返回结果有真实链接。明确为站内导航，不假装调用 AI。独立 Demo 是拖动交互面，使用明确返回项目链接，避免叠放第二个悬浮助手干扰操作。
- **I02 完整状态**：空输入显示建议；无匹配显示清空操作；索引失败保留页面导航与“查看全部文章”。Esc、关闭按钮和点击遮罩可关闭；焦点回到触发元素，背景在模态期间不可操作；不会在输入框内误拦截普通快捷键。
- **I03 项目展台**：首页点击三种阶段切换图像、说明和当前选择，默认内容静态可见。声明为流程示意，附真实 Demo 与项目链接。键盘使用原生按钮可完整操作，切换结果适度播报。
- **I04 阅读路径**：长文章有阅读进度与“本页章节”；当前位置随滚动更新，返回顶部合并进助手；文章筛选有选中语义和结果数。章节深链接仍可分享。
- **I05 动态边界**：交互反馈约 160–240ms；入场轻微、一次性。支持 prefers-reduced-motion，不自动打字、循环轮播、滚动劫持、隐藏主内容或自动播放声音。JS 失败时所有正式内容仍可阅读，主导航仍可用。

## 4. 清理与技术维护

- **M01**：建立 AGENTS + specs 单一工作入口，归档旧方案、保留研究依据、清理明确无调用的代码和失效承诺，逐项记录处置。
- **M02**：静态架构不迁移框架；替换旧主题文件为 `css/portfolio.css`，删除已淘汰首页样式及无调用的动态卡片生成代码；不无限追加全站覆盖层。
- **M03**：正式发布使用白名单构建，排除 tmp、resume-redesign、search、paper_search、docs、specs、ai-prep、文章模板。历史求职工具保留源文件并明确归档属性。
- **M04**：保留六篇文章、两篇项目详情、演示及其路由。修复子页导航高亮。更新 sitemap 修改日期时不改文章发表日期。
- **M05**：不覆盖已有简历改动，不删除未跟踪资料，不新增公开手机号。数据不上传模型或第三方检索服务。

## 5. 验收门槛

| 要求 | 证据 |
| --- | --- |
| V01–V04 | 首页/内页桌面与 320px 截图；全正式路由宽度与图像检查；颜色计算 |
| I01–I02 | 打开、检索、无结果、请求失败、关闭、焦点恢复、键盘导航测试 |
| I03 | 三阶段按钮内容切换、选择状态、真实出口；无 JS 默认内容 |
| I04–I05 | 章节跳转/阅读进度、筛选计数、reduced-motion、无 JS、履历打印检查 |
| M01–M05 | 文档引用、清理台账、静态校验、diff 检查、产物白名单核对 |
| 交付 | 本地运行和预览可用；发布行为及实际状态单独记录 |

## 6. 实施顺序

规格与调研 → 首页代表切片与首次预览 → 全站视觉/内容收敛 → 助手与阅读交互 → 归档/发布边界 → 全路由和交互验证 → 修正并记录交付。

## 7. 范围判断

悬浮助手先实现确定性的站内导航与搜索，无需模型成本，也不会生成不存在的页面。拖拽桌宠、3D 世界、主题商城、CMS、实时岗位数据与未提供素材的新故事不属于本轮。已有 Demo 保留，不能把模拟当成真实系统运行。
